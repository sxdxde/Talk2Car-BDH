\section{Task \& Motivation}

% ------------------------------------------------------------------
\begin{frame}{The Task: Visual Grounding}
  \begin{columns}[T]
    \begin{column}{0.55\textwidth}
      \textbf{Visual grounding} (Talk2Car): given an image and a
      natural-language command, localize the single object the
      command refers to.
      \vspace{0.4cm}

      \textit{``Turn left behind the silver car''} $\rightarrow$
      one bounding box.

      \vspace{0.4cm}
      Scenes with \textbf{multiple objects of the same class} are the
      harder case — the model has to use the language to tell them
      apart, not just detect objects.
    \end{column}
    \begin{column}{0.45\textwidth}
      \begin{block}{Baseline model}
        \textbf{AttnGrounder} (Mittal et al., 2020) — single-stage,
        Darknet-53 + BiLSTM/GloVe, a lightweight \emph{visual--text
        attention} module fuses the two modalities before a YOLO head.
      \end{block}
    \end{column}
  \end{columns}
\end{frame}

% ------------------------------------------------------------------
\begin{frame}{Why Look at BDH?}
  \small
  \begin{block}{Dragon Hatchling (BDH) — Kosowski et al., Pathway, 2025}
    \small A recently published sequence architecture whose working
    memory is an \textbf{explicit, growing outer-product associative
    memory} ($\rho = K^\top V$), updated with Hebbian-style
    read/write, rather than compressed into a fixed-size state the way
    SSMs such as Mamba do.
  \end{block}
  \vspace{0.15cm}
  \begin{center}
  \begin{tikzpicture}[
      node distance=5mm,
      box/.style={draw, rounded corners, minimum height=0.8cm, minimum width=2.5cm, align=center, font=\scriptsize, fill=blue!6},
      arrow/.style={-{Stealth[length=2mm]}, thick}
  ]
    \node[box] (lift) {ReLU lift into a\\high-dim, sparse space};
    \node[box, right=of lift] (mem) {Explicit outer-product\\memory $\rho=K^\top V$};
    \node[box, right=of mem] (gate) {Multiplicative\\(bilinear) gate};
    \draw[arrow] (lift) -- (mem);
    \draw[arrow] (mem) -- (gate);
  \end{tikzpicture}
  \end{center}
  \vspace{0.1cm}
  \begin{block}{The question this project asks}
    \small BDH has, as far as we can tell, not previously been
    evaluated on any cross-modal (vision + language) task. We wanted
    to see whether it can be substituted for an established,
    years-refined attention mechanism in a grounding model, and what
    happens to accuracy, parameter count, and compute cost when we do.
  \end{block}
  \vspace{0.05cm}
  \footnotesize\textit{A more specific hypothesis about why BDH's
  memory might help is discussed later, once the main comparison has
  been presented.}
\end{frame}

% ------------------------------------------------------------------
\begin{frame}{BDH and Related Memory Architectures}
  \small
  \begin{itemize}\setlength{\itemsep}{3pt}
    \item BDH's original paper reports experiments on \textbf{language
      modeling and machine translation only}, at GPT-2-like parameter
      scales (10M--1B). We did not find vision or cross-modal
      experiments described in the paper text we read (its Appendix E
      code listing did not extract cleanly for us, so we cannot fully
      rule out something there, but nothing in the main text describes
      one).
    \item \textbf{State-space models (e.g.\ Mamba)} compress context
      into a fixed-size hidden state; BDH's memory instead grows with
      the input. This contrast motivates testing BDH on a task that
      plausibly rewards keeping distinguishing information around
      rather than compressing it — a hypothesis we treat as untested,
      not an established property of BDH.
    \item We read the papers collected for this project (BDH;
      AttnGrounder; ThinkDeeper; IRRA — a cross-modal relation-reasoning
      paper for a different task, text-to-image person retrieval) and
      ran an ad hoc search (via Consensus) around adjacent ideas such as
      distractor-based hard negatives. We found no prior work applying
      BDH to visual grounding or any cross-modal task.
    \item Not a systematic literature review — absence of a result in
      our search is evidence of a gap, not proof no such work exists.
  \end{itemize}
\end{frame}

    \end{column}

      \small\textbf{BDH module:} symmetric or causal-context kernel

      shapes, so it can be substituted without changing the rest of
      the network.
    \end{column}
  \end{columns}
\end{frame}

\begin{frame}{How Modes A, B, C Fit Into the Architecture}
  \footnotesize BDH was designed for causal, single-sequence language
  modeling. Grounding has no inherent order between ``words'' and
  ``regions,'' so we tried three different ways of adapting the
  mechanism; only Mode C has been trained and evaluated end-to-end so
  far (Modes A and B are implemented and ran, see Results).
  \begin{center}
  \scalebox{0.8}{
  \begin{tikzpicture}[

  ]

    \node[lbl] (cLbl) {Mode C (primary)};
    \node[box, fill=green!10, below=of cLbl] (cWords) {Words $\to$ key/value addresses};
    \node[box, fill=green!10, below=of cWords] (cRegions) {Regions $\to$ query addresses};
    \node[box, fill=green!10, below=of cRegions] (cMem) {Memory $\rho$ built once from all words};
    \node[box, fill=green!10, below=of cMem] (cRead) {Every region reads $\rho$ in parallel (non-causal)};
    \draw[-{Stealth[length=1.5mm]}] (cWords) -- (cMem);
    \draw[-{Stealth[length=1.5mm]}] (cMem) -- (cRead);
    \draw[-{Stealth[length=1.5mm]}] (cRegions) -- (cRead);

    \draw[-{Stealth[length=1.5mm]}] (bCat) -- (bSelf);

  }
  \end{center}
  \vspace{0.1cm}
  \tiny Mode C keeps BDH's memory mechanism but drops the causal mask
  and RoPE (no ordering assumption between words and regions). Modes A
  and B keep more of BDH's original causal design, closer to how it was
  used for language modeling.
\end{frame}

% ------------------------------------------------------------------
\begin{frame}{Keeping the Comparison Fair}
  \begin{itemize}
    \item \textbf{Single component swap}: backbone, text encoder, YOLO
      head, losses, hyperparameters — all identical between variants.
    \item \textbf{Fusion trim}: BDH fuses only $[f_{visu}, f_{lang\_attn}]$
      (2 streams) instead of the original 3, to offset most of the
      module's added parameters.
    \item \textbf{Same training recipe for all variants}: A100-40GB,
      bf16, 100 epochs, Adam (lr $10^{-4}$, backbone lr$/10$), batch
      14, poly LR schedule.
  \end{itemize}
  \vspace{0.3cm}
  \begin{table}
    \centering\small
    \begin{tabular}{lccc}
      \toprule
      Variant & Params & vs.\ baseline \\
      \midrule
      Baseline (AttnGrounder, unmodified) & 75.84M & --- \\
      BDH (any mode, single-head) & 76.63M & $+0.79$M ($+1.0\%$) \\
      \bottomrule
    \end{tabular}
  \end{table}
  \small The backbone dominates parameter count either way — this is a
  fusion-mechanism comparison, not a capacity comparison.
\end{frame}

\section{How We Measure Success}

% ------------------------------------------------------------------
\begin{frame}{The Metrics, Explained}
  \begin{columns}[T]
    \begin{column}{0.5\textwidth}
      \begin{block}{AP50 (our main number)}
        \small A prediction counts as \textbf{correct} if the
        predicted box overlaps the ground-truth box by
        \textbf{Intersection-over-Union} $\geq 0.5$. AP50 = \% of
        commands localized correctly.
      \end{block}
      \begin{center}
      \scalebox{0.55}{
      \begin{tikzpicture}[every node/.style={font=\small}]
        \draw[thick, blue!70] (0,0) rectangle (2.4,1.8);
        \node[blue!70, above] at (1.2,1.8) {Ground truth};
        \draw[thick, orange!80!black] (1.0,0.6) rectangle (3.2,2.2);
        \node[orange!80!black, above] at (3.2,2.2) {Predicted};
        \begin{scope}
          \clip (0,0) rectangle (2.4,1.8);
          \fill[green!50!black, opacity=0.35] (1.0,0.6) rectangle (3.2,2.2);
        \end{scope}
        \node at (1.6,-0.4) {IoU $=\frac{\text{overlap}}{\text{union}} \geq 0.5 \Rightarrow$ hit};
      \end{tikzpicture}
      }
      \end{center}
    \end{column}
    \begin{column}{0.5\textwidth}
      \begin{block}{Params}
        \footnotesize Total trainable parameters — a proxy for model
        size / compute cost. Lower is ``lighter.''
      \end{block}
      \begin{block}{Ambiguous vs.\ Unambiguous (Step 6)}
        \footnotesize The stratification used to test our hypothesis
        — \textbf{ambiguous}: $\geq 1$ other same-class object in
        frame; \textbf{unambiguous}: referred object is the only one
        of its class. Built from nuScenes 3D metadata — see next
        slide.
      \end{block}
    \end{column}
  \end{columns}
\end{frame}

% ------------------------------------------------------------------
\begin{frame}{Step 6: Stratifying the Val Set}
  Talk2Car's own annotations only record the \emph{referred} object —
  not what else is in the scene. To test the hypothesis we need to
  know, per image, how many \textbf{other} objects share the referred
  object's class.

  \begin{block}{Data pipeline built for this}
    Join Talk2Car commands $\to$ nuScenes \texttt{v1.0-trainval}
    metadata (front-camera 3D annotations) via the sample token $\to$
    count same-class objects visible in \texttt{CAM\_FRONT}.
  \end{block}

  \begin{table}
    \centering\small
    \begin{tabular}{lcc}
      \toprule
      Bucket & Definition & Count (val, $n{=}1163$) \\
      \midrule
      Ambiguous & $\geq 1$ other object, same class & 830 \\
      Unambiguous & referred object is unique in class & 333 \\
      \bottomrule
    \end{tabular}
  \end{table}
\end{frame}

% ------------------------------------------------------------------
\begin{frame}{Reading the Ablation Results}
  \begin{block}{Observations}
    \small Mode A's mean (3 seeds) is slightly above baseline's mean (2
    seeds) on aggregate AP50 ($+0.17$); Mode E improves on its own base
    kernel ($+0.69$ over Mode C) and is above baseline on unambiguous
    scenes. Taken together, a mechanism with no prior cross-modal
    testing performs \emph{comparably to} an attention mechanism that
    has had years of task-specific refinement, on this one benchmark
    and this one architecture.
  \end{block}
  \vspace{0.2cm}
  \small
  \begin{itemize}
    \item These differences are small relative to the seed-to-seed
      variance shown on the previous slide, so we read them as
      directional rather than conclusive with only 2--3 seeds per
      variant.
    \item Not every kernel formulation works — Mode B (60.53) is a
      clear regression — so this is not ``any BDH variant helps,'' it
      appears to depend on the specific design choice.
  \end{itemize}
  \vspace{0.2cm}
  \small\textit{Why does this hold up, mechanistically, if it does?
  We had a specific hypothesis going in — see ``Examining the
  Motivating Hypothesis'' later for what the data actually shows.}
\end{frame}

    $+12.5\%$ increase in inference time. We think all three numbers
    belong in the writeup together.
  \end{block}
\end{frame}

\section{Positioning Relative to Prior Work}

% ------------------------------------------------------------------
\begin{frame}{Where This Differs From Prior Work}
  \scriptsize\textit{Based on the reading and searching described under
  ``Related Work'' — framed as ``we did not find this elsewhere,'' not
  as an unfalsifiable ``first ever.''}
  \vspace{0.1cm}
  \begin{block}{BDH applied to cross-modal grounding}
    \scriptsize BDH's own paper evaluates language modeling and
    translation only. We did not find it applied to vision, to
    cross-modal fusion, or to Talk2Car anywhere in the literature we
    reviewed — as far as we can tell, this is a first attempt at a
    cross-modal grounding application.
  \end{block}
  \begin{block}{Three non-causal kernel adaptations}
    \scriptsize BDH was designed causal/autoregressive (language has
    sequence order; grounding does not). Modes A/B/C are our own
    adaptations of BDH's associative-memory mechanism to a non-causal,
    bimodal setting, not a direct reuse of the original code.
  \end{block}
  \footnotesize
  \begin{itemize}\setlength{\itemsep}{1pt}
    \item \textbf{Quantitative ambiguity stratification}: nuScenes-joined
      same-class-object counting on Talk2Car's val split (not shipped
      with the dataset) — tests the hypothesis at the sub-population
      level, not just in aggregate.
    \item \textbf{The fusion trim as a confound control}: holds params
      near-parity ($+1\%$) with baseline, so the mechanism swap is close
      to the only variable changing — several papers we read change
      backbone, mechanism, and data together, which makes it harder to
      attribute gains to any one factor.
  \end{itemize}
\end{frame}

\section{Methodology}

% ------------------------------------------------------------------
\begin{frame}{A Note on Methodology: Why Val, Not Test}
  \begin{itemize}
    \item Talk2Car's test-set ground truth has \textbf{never been
      publicly released} — the only historical evaluation path was an
      AIcrowd-hosted server (ECCV 2020 C4AV challenge).
    \item That server \textbf{closed to submissions in August 2020}.
      We found no evidence of a live replacement.
    \item AttnGrounder and CMSVG were published while that server was
      still open, so their test numbers are plausibly server-verified.
      Papers reporting Talk2Car ``test'' scores since then
      (TransVG 2021, RSD-LXMERT 2022, CAVG/ThinkDeeper 2024--2025) all
      point to that same closed evaluation path — their numbers look
      most likely \textbf{self-reported}, and we could not verify how
      they were produced.
  \end{itemize}
  \vspace{0.3cm}
  \begin{block}{Our choice}
    We report \textbf{val-set AP50 only}, explicitly caveated against
    other papers' self-reported test numbers. This is less flattering
    than quoting a test number, but it is the number we can stand
    behind — directionally informative, not a strict apples-to-apples
    comparison with every row in the tables above.
  \end{block}
\end{frame}

\section{Examining the Motivating Hypothesis}

% ------------------------------------------------------------------
\begin{frame}{The Hypothesis Behind This Project}
  \begin{block}{``Grounding = in-context retrieval''}
    Our starting idea: architectures with an explicit associative
    memory might have an edge specifically when a query has to be
    matched against \textbf{multiple similar candidates} in context —
    framing that as a retrieval problem rather than a compression
    problem (BDH's memory is explicit and growing; SSMs like Mamba
    compress to a fixed-size state instead).
  \end{block}
  \vspace{0.2cm}
  \textbf{Prediction:} swapping in BDH should raise AP50
  \emph{disproportionately} on scenes with several same-class candidate
  objects (``ambiguous,'' $n{=}830$) relative to scenes with only one
  (``unambiguous,'' $n{=}333$) — tested via the nuScenes-joined
  stratification described earlier (Step 6).
  \vspace{0.2cm}
  \small\textit{This was the project's original motivating question; it
  came before the results, not after, and we think it is worth being
  explicit about that.}
\end{frame}

% ------------------------------------------------------------------
\begin{frame}{Result: Hypothesis Not Supported}
  \begin{alertblock}{Across every configuration tested}
    \footnotesize Mode A ($\times 3$ seeds), B, C, E — all 6 BDH data
    points — none clearly exceed baseline's own observed
    ambiguous-scene range (64.04 mean, 63.37--64.70 across seeds). The
    disproportionate ambiguous-scene advantage the hypothesis predicted
    does not show up consistently across the ablation.
  \end{alertblock}
  \vspace{0.2cm}
  \small
  \begin{itemize}
    \item Where BDH \emph{does} come out ahead (Mode A's aggregate,
      Mode E's unambiguous gain), it is concentrated in the
      \emph{opposite} bucket from what the hypothesis predicted — the
      easier, single-candidate scenes, not the harder disambiguation
      cases.
    \item Mode B — the variant closest to BDH's original causal,
      sequential design — is the weakest performer, not the strongest,
      which argues against a simple ``more associative memory means
      more retrieval benefit'' story.
  \end{itemize}
  \vspace{0.2cm}
  \begin{block}{Why report a negative result at all?}
    \footnotesize It answers the question that motivated the project,
    even though the answer is ``no.'' It also tells us the viability
    result above isn't coming from the mechanism we originally expected,
    which narrows down what to look at next.
  \end{block}
\end{frame}

\section{Additional Experiments}

% ------------------------------------------------------------------
\begin{frame}{Additional Experiments — A Retrospective}
  \footnotesize Four follow-up experiments after the ablation study,
  each carried through to a real conclusion rather than left open:
  \begin{itemize}\setlength{\itemsep}{3pt}
    \item \textbf{Tversky + Focal loss} (replacing BCE on the
      $\beta$/attention-map supervision): \textcolor{red!70!black}{negative}
      — 64.03, below Mode A's 65.09. The aux loss only carries $10\%$
      weight in the total objective, so there may not be enough
      leverage for it to matter.
    \item \textbf{Cross-scale growing memory (Mode E)}: a real
      \emph{within-mechanism} improvement ($+0.69$ over its own base
      kernel, Mode C) — but still no advantage over baseline on
      ambiguous scenes specifically. See Results.
    \item \textbf{Offline/frozen pretrained text encoder} (DistilBERT,
      replacing GloVe+BiLSTM): \textcolor{red!70!black}{substantial
      regression} — 59.98 vs.\ baseline's 64.92. A LayerNorm fix
      (targeting a real BERT-scale mismatch) recovered only $+0.52$.
      Our best guess at the root cause: a fully \emph{frozen} encoder
      has almost no capacity to adapt to this task. We
      \textbf{paused} this track rather than abandoning it — partial
      fine-tuning or domain-adaptive pretraining seem like more
      promising next steps than another architectural tweak.
    \item \textbf{Efficiency metrics}: done — see earlier slide.
  \end{itemize}
  \vspace{0.15cm}
  \footnotesize\textit{Scoped out for now: YOLOv7/YOLO26 backbone swap,
  BDH stacking, a BDH$\to$attention hybrid, a distractor-contrastive
  loss — plausible ideas we did not chase further once the AttnGrounder
  phase had a complete answer we felt comfortable reporting.}
\end{frame}

\section{Cross-Architecture Check}

% ------------------------------------------------------------------
\begin{frame}{Cross-Architecture Check: TransVG}
  \small
  \begin{block}{The question}
    \scriptsize Everything so far is one architecture (AttnGrounder,
    2020, narrow region$\leftrightarrow$word cross-attention). Does
    BDH's viability hold on a structurally different design, or is it
    specific to that integration point?
  \end{block}
  \vspace{0.08cm}
  \begin{block}{TransVG (Deng et al., ICCV 2021) — same recipe, one variable changed}
    \scriptsize BDH swapped into TransVG's V-L fusion \textbf{self}-attention
    (6 stacked layers over $\sim$421 tokens: 1 reg + 20 text + $\sim$400
    visual) — a structurally different role than AttnGrounder's narrow
    cross-attention. We verified a healthy baseline (55.20\% val accu)
    and correct plumbing (an overfit-8-sample probe cleanly memorizes).
  \end{block}
  \vspace{0.08cm}
  \begin{alertblock}{Result: BDH plateaus at roughly half the baseline}
    \scriptsize \textbf{Baseline 55.20\%} vs.\ \textbf{BDH 26.23\%} val
    accu (best epoch, same epoch for both) — the same overfit probe
    (softmax MHA reaches 1.0 accu on 8 fixed samples; BDH plateaus at
    $\sim$0.5--0.625) suggests this is a real, consistent gap, not a
    bug.
  \end{alertblock}
  \vspace{0.05cm}
  \scriptsize\textbf{A plausible explanation, not a confirmed one:}
  TransVG forces one pooled associative memory from all $\sim$421
  tokens as both keys and values; visual tokens outnumber text/reg
  tokens 20:1 and may dominate it, with no per-token normalization to
  protect the signal, compounded across 6 stacked layers — untested,
  see Future Work.
\end{frame}

\section{Future Work}

% ------------------------------------------------------------------
\begin{frame}{Possible Next Steps}
  \scriptsize None of the following is committed work, just what
  currently looks worth trying based on where the results leave off:
  \begin{itemize}\setlength{\itemsep}{2pt}
    \item \textbf{Test the TransVG explanation directly}: add per-token
      normalization to BDH's self-attention memory read and see whether
      that narrows the gap to baseline, rather than concluding
      self-attention roles are unsuitable for BDH based on one
      architecture.
    \item \textbf{Revisit the frozen text-encoder track}: partial
      DistilBERT fine-tuning or domain-adaptive continued pretraining
      instead of a fully frozen encoder — paused, not abandoned, and
      the more promising of the two remaining fixes identified.
    \item \textbf{Distractor-contrastive auxiliary loss} (queued, not
      yet implemented): use the nuScenes-derived same-class distractor
      locations already built for Step 6 as hard negatives in a margin
      loss on $\beta$ — untested, may or may not help.
    \item \textbf{Multi-head BDH}: everything reported here uses a
      single head; multi-head is an unexplored capacity/parameter
      trade-off.
    \item \textbf{Independent test-set verification}: given the
      val/test caveats discussed earlier, contacting the Talk2Car
      maintainers about research-use test-set access would let
      comparisons happen on a currently-verifiable split.
    \item \textbf{Backbone modernization} (e.g.\ a newer detector than
      Darknet-53): scoped out so far because it changes more than one
      variable at once; if pursued, it would need to apply identically
      to baseline and BDH variants to stay a fair comparison.
  \end{itemize}
\end{frame}

\section{Conclusion}

% ------------------------------------------------------------------
\begin{frame}{Overview of Findings}
  \tiny Three separate findings, reported here together rather than
  leading with any one of them:
  \vspace{-0.1cm}
  \begin{block}{On AttnGrounder's narrow cross-attention: a scoped positive result}
    \tiny A memory architecture published under a year ago, with no
    prior cross-modal validation that we found, achieves AP50
    comparable to — and, on the aggregate mean across our seeds,
    slightly above — an established, years-refined softmax attention
    mechanism, with no task-specific tuning of the BDH mechanism itself
    ($+1\%$ params, $+15\%$ compute). A real but \emph{narrow} result,
    specific to this integration point.
  \end{block}
  \vspace{-0.15cm}
  \begin{alertblock}{The mechanism behind it is not what we predicted}
    \tiny Across every AttnGrounder configuration tested (3 kernel
    modes, multi-seed on the best one, the growing-memory extension),
    BDH shows \textbf{no disproportionate advantage on ambiguous,
    multi-candidate scenes} — the ``grounding = in-context retrieval''
    idea that motivated this project. Reported as a genuine negative
    result, not a footnote.
  \end{alertblock}
  \vspace{-0.15cm}
  \begin{alertblock}{It does not generalize naively to every attention role}
    \tiny Ported to TransVG's \emph{self}-attention (dense, one pooled
    memory over $\sim$421 visual-dominated tokens) instead of
    AttnGrounder's narrow cross-attention, BDH plateaus at
    \textbf{roughly half} the baseline (26.23\% vs.\ 55.20\% val accu),
    which an overfit probe suggests is a real limitation, not a bug.
    Viability observed on AttnGrounder appears \emph{role-specific}.
  \end{alertblock}
  \vspace{0.05cm}
  \tiny\textbf{What differs from prior work:} a first cross-modal
  application of BDH, as far as we found; three non-causal kernel
  adaptations of an inherently causal mechanism; a reusable
  ambiguity-stratification protocol; and a partial characterization of
  which attention role suits BDH's memory. Negative findings belong
  alongside the positive one, not underneath it.
\end{frame}

% ------------------------------------------------------------------
\begin{frame}{Summary}
  \scriptsize
  \begin{itemize}
    \item \textbf{Main result}: on AttnGrounder's narrow cross-attention,
      a memory architecture published under a year ago, with no prior
      cross-modal testing that we found, performs comparably to
      established softmax attention (mean AP50 65.09 vs.\ 64.92 across
      seeds), with no task-specific tuning of the mechanism.
    \item Built a validated, drop-in BDH swap (3 kernel modes + a
      cross-scale extension) for AttnGrounder, a from-scratch baseline
      reproduction, and a nuScenes-based ambiguity-stratification
      pipeline.
    \item Efficiency, reported together rather than cherry-picked:
      $+1\%$ params, $+15\%$ GFLOPs, $+12.5\%$ inference time.
    \item \textbf{Multi-seed testing}: the original motivating
      hypothesis — a specific edge on ambiguous, multi-candidate
      scenes — did not hold up under seed-tested scrutiny. An
      encouraging single-seed result did not replicate.
    \item \textbf{Cross-architecture check (TransVG)}: the viability
      finding does \emph{not} generalize naively — BDH self-attention
      over TransVG's dense, visual-dominated tokens plateaus at
      roughly half the baseline (26.23\% vs.\ 55.20\%). We believe this
      is a real boundary, not a bug, though we have not yet tested our
      leading explanation for it (see Future Work).
    \item Several concrete next steps identified (Future Work) — none
      of them started yet.
  \end{itemize}
  \vspace{0.3cm}

\end{frame}
